An App for Git

A native iPhone and iPad client for GitHub and GitLab, built first for the foldable iPhone Duo.

One Inbox for reviews, mentions, builds and approvals across all your accounts. Read and review pull requests and merge requests, browse code, follow builds and handle security alerts, on github.com, gitlab.com and your own servers.

With An App for Git Companion on your Mac, you can see and message the AI coding agents you run in herdr, get an alert when one needs you, and answer it from your phone.

No accounts with us, no servers, no tracking. Your data goes between your devices, your code hosts and your own iCloud.
